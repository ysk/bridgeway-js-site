    ⑤ 二重送信

    bridgey — 送信処理だけ書く

$$("#submit").disabled(f.submitting);

    method: "POST", body: JSON.stringify(values),
  });
});

// 実行中の再送信は無視される
// 失敗しても submitting は必ず戻る
    jQuery — フラグを手で管理する
    var sending = false;
$("#form").on("submit", function (e) {
  e.preventDefault();
  if (sending) return;
  sending = true;
  $("#submit").prop("disabled", true);
  $.post("/api", $(this).serialize())
    .always(function () {
      sending = false;
      $("#submit").prop("disabled", false);
      // ↑ 戻し忘れると永久に押せない
    });
});

      カートのコード

      bridgey 側は、いま上で動いているコードそのものです。タブで切り替えてください。

      右は「計算して代入する」、左は「導出する」。 jQuery 側は calcTotal() を数量変更・削除・クーポン・初期表示の4箇所から呼び、 さらに表示先の数だけ .text() で代入しています。 呼び忘れも書き忘れも起こりうる場所が、それだけあるということです。 bridgey 側には金額に代入している行が1つもないので、ズレようがありません。

      ToDo（一覧の状態管理）

      追加・完了・削除・絞り込み・残り件数。一覧は repeat() が描くので、 入力途中の文字やチェック状態が消えません。

        該当するものがありません

        メモ欄に何か入力してから、別の項目を追加・完了・削除してみてください。入力した文字は消えません。

        ToDo のコード

        bridgey 側は、いま上で動いているコードそのものです。タブで切り替えてください。

        .html() で作り直すと、入力途中の文字もフォーカスも消えます。 bridgey の repeat() はキーが同じ行の DOM を使い回すので、 上のデモでメモ欄に入力したまま追加や絞り込みをしても消えません。 件数の更新も導出なので、updateCounts() の呼び忘れ自体が存在しません。

        壊れにくさ — bridgey が黙らせない事故

        ここから下は「同じ画面をどう書くか」ではなく、 書き方に関係なく襲ってくる事故を bridgey がどう止めるかの実演です。 どれもその場で触って確かめられます。

        HTML を1段ラップすると、黙って壊れる

        next() や children() で「隣の要素」を掴んでいるコードは、 HTML に要素を1つ挟むだけで動かなくなります。しかも例外は出ません。
        デザイナーが <div> を1枚足しただけ——という壊れ方です。

        従来のやり方（隣を掴む）
        基本料金 23,800円 ／ 追加料金 2,200円

        まだ壊れていません。

        bridgey（名前で引く）
        基本料金 23,800円 ／ 追加料金 2,200円

        まだ壊れていません。

        1つの undefined で、全機能は死なない

        同じ $(function(){}) の中に全部書いていると、 最初の1行が落ちた時点で、後ろのタブもカウンターも巻き添えで死にます。
        bridgey は部品ごとに切り離すので、壊れた部品だけが止まります。

        料金の中身です。
        スペックの中身です。

        この上には初期化に失敗した部品が1つ混ざっています（コンソールに理由が出ています）。 それでもタブとカウンターは動きます。

        class 名のタイポは、その場で教える

        表示の出し入れを class で行っていると、綴りを間違えた瞬間に「隠したはずのものが見えたまま」になります。 CSS に無いクラスで状態を切り替えようとしたら、bridgey は似ている名前を添えて知らせます。

        押すと、bridgey が出す警告をそのまま表示します。
