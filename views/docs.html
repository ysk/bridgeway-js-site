ドキュメント

まず覚えるのは state / computed / when / repeat の4語だけ。 あとは知っている jQuery のメソッドがそのまま使えます。
依存ゼロ・ビルド不要・gzip 16kB・eval 不使用（CSPセーフ）。

bridgey とは

保守する人のためのライブラリです。jQuery で書かれた画面を、書き直さずに事故だけ止めるための道具です。
すべて実在のコードで起きていた事故が出発点です。

  • 数字（金額など）の合計値が合わない — 合計を「代入する場所」を無くしました
  • 非表示の必須項目で送信できない — 見えているフィールドだけを検証します
  • オートフィルで未入力扱い — 値の代入自体を検知します
  • HTMLの構造が変わりJSが壊れる — 名前で引き、0件なら警告します
  • 1つの undefined で全機能が死ぬ — 部品単位でエラーを隔離します
  • 日本語入力で壊れる — 変換中は値を触りません

ビルド環境も、HTML の書き換えも、既存 jQuery の削除も、全面書き直しも要求しません。
<script> 1行を足して、1機能だけ置き換えられます。

インストール

今すぐ試すなら <script> 1行。型が欲しくなったら npm。

<!-- これだけ。ビルド不要 -->
<script src="https://cdn.jsdelivr.net/npm/bridgey@2"></script>
npm install bridgey
import { $$ } from "bridgey";
import { $$ as $ } from "bridgey";   // 好きな名前にできる

はじめの一歩

demo.html という名前で保存して、ブラウザで開くだけです。これで全部です。

<!doctype html>
<html lang="ja">
<head>
<meta charset="utf-8">
<title>demo</title>
</head>
<body>

<p>合計 <span id="total">0</span> 円</p>
<button id="add">追加する</button>

<script src="https://cdn.jsdelivr.net/npm/bridgey@2"></script>
<script>
  const count = $$.state(0);
  const total = $$.computed(() => count() * 1100);

  $$("#total").text(total, $$.money);
  $$("#add").click(() => count(n => n + 1));
</script>

</body>
</html>

サーバも、ビルドも、npm install も要りません。
total に代入している行はありません。導出しているだけなので、更新漏れが起きません。

増えた概念は1つだけ

$$("#total").text("1,100");  // 値を渡す    → その瞬間だけ入る（jQuery と同じ）
$$("#total").text(total);      // state を渡す → 以後ずっと自動で追いかける ← これだけが新しい

関数を渡すと、その中で読んだ状態を自動で追跡します。

$$("#label").text(() => `${count()}個 / ${total()}円`);

セレクタと @ 略記

id も class も今まで通り使えます。HTML を変えられない現場でも、そのまま動きます。
data-brg は推奨ですが、必須ではありません。HTML を触れるなら、こちらの方が壊れにくくなります。 @ はその属性の省略記法です。 

$$("#total")   // id="total"
$$(".total")   // class="total"
$$("@total")   // data-brg="total"  ← [data-brg="total"] の略記
$$("@list @row")         // 組み合わせもできる
$$("@list").find("@row")  // find / closest / 委譲セレクタでも使える

class は見た目のためのものなので、デザイナーが変えます。それを JS が掴んでいると壊れます。 掴む名前を data-brg に分ければ、class をいくら変えても JS は壊れません。 属性名は $$.attr = "data-ui" で変更できます。

state

読み書きの規約は jQuery と同じ（引数なしで読む・ありで書く）。

const count = $$.state(0);

count()            // 読む
count(5)           // 書く
count(n => n + 1)  // 更新
`${count}`         // 補間もできる（count > 3 のような比較も）
count.peek()       // 購読せずに覗く

要素に結びつけることもできます。側面は要素から推論されます。

const label = $$("#total").state(0);        // span → textContent
const name  = $$("#name").state("");       // input → value（双方向）
const agree = $$("#agree").state(false);   // checkbox → checked（双方向）
const src   = $$("#img").state(url, "attr:src");  // 明示もできる
const now   = $$("#total").state();           // 引数なし → DOM の現在値が初期値

側面: value / checked / text / html / attr:名前 / class:名前 / css:プロパティ

computed

依存は自動追跡。読まれるまで計算しません。結果が変わらなければ画面も触りません。

const total  = $$.computed(() => items().reduce((s, i) => s + i.price, 0));
const isFree = $$.computed(() => total() >= 5000);
const label  = $$.computed(() => `${items().length}点 / ${total()}円`);

書き込もうとすると例外になります（読み取り専用）。

when

$$("#error").when(hasError);                    // display の出し入れ
$$("#modal").when(open, { detach: true });    // 偽なら DOM から外す
$$("#free").when(() => qty() >= 3);              // 関数でも書ける

見せてはいけないものは detach: true を使ってください。 CSS で隠す方式は、class 名のタイポや CSS の1行削除で見えてしまう側に倒れます。 DOM から外せば CSS に依存しません。

repeat

行の DOM を使い回すので、入力途中の文字・フォーカス・スクロール位置が飛びません。

<ul id="list"></ul>
<template id="row"><li><span class="title"></span><input class="memo"></li></template>

$$("#list").repeat(todos, {
  key: (t) => t.id,             // 一意な値。省略すると位置(index)になる
  tpl: "#row",                // <template> を雛形にする
  render: ($row, t) => {        // 中身はいつもの jQuery
    $row.find(".title").text(t.title);
  },
});

サーバーが出力済みの一覧を乗っ取ることもできます（HTML を1文字も変えません）。

$$("#list").repeat(rows, { from: "li", key: (r) => r.id, render: … });

簡単な行なら文字列でも書けます。

$$("#list").repeat(todos, (t) => `<li>${t.title}</li>`);

<table> の <tr> や <select> の <option> でも動きます（テスト済み）。 <select> では項目を増やしても選択中の値が消えません。
キーが重複していると警告します。

$$( ) が受け取れるもの

$$("#id") $$(".class") $$("@name") $$("a[href]")   // セレクタ
$$("<li>x</li>")      // HTML 生成
$$(el) $$(nodeList) $$([el1, el2]) $$($$(…))
$$(document) $$(window)  // イベント用
$$(function () { … })   // DOM ready

プロパティ: .length / .el（先頭の要素） / .els（配列）

text / html / val / attr / prop / css

引数なしで読む・値で書く・state で束縛する、の3態です。

$$("#t").text()            // 読む
$$("#t").text("完了")      // 書く
$$("#t").text(total)        // 束縛（以後ずっと追従）

text() は「値 → 加工 → 形」の順に引数を足せます。

$$("#n").text(count)                        // 3
$$("#n").text(count, "件")                  // 3件
$$("#n").text(count, "残り{}件")            // 残り3件
$$("#n").text(total, $$.money, "円")       // 23,800円
$$("#n").text(count, (v) => v * 1.1, "円")  // 加工してから

その他も同じ形です。

$$("#img").attr("src", url);
$$("#btn").prop("disabled", busy);
$$("#q").val(keyword);                   // 双方向
$$("#bar").css("width", () => `${pct()}%`);
$$("#row").data("id", id);
$$("#box").addClass("a b").removeClass("c").hasClass("a");
$$("#box").toggleClass("is-open", open);   // 真偽の state で付け外し

UI 状態（selected / disabled …）

.addClass("active") の代わりに「UI がどういう状態か」を書けます。 ARIA 属性と data- 属性が同時に付くので、CSS も支援技術も同じ状態を見ます。 

$$("#tab").selected(isCurrent);   // aria-selected + [data-selected]
$$("#head").expanded(isOpen);    // aria-expanded（false も明示）+ [data-expanded]
$$("#mail").invalid(hasError);   // aria-invalid + [data-invalid]
$$("#list").busy(loading);       // aria-busy + [data-busy]
$$("#save").disabled(sending);   // 本物の disabled（a タグなら aria-disabled）

引数なしで現在値を読めます（$$("#save").disabled()）。静的な真偽値も渡せます。

mode / toggleAttr / vars

排他的な状態は属性1つで表します。class は「消し忘れ」で2つ付きますが、属性は構造的に1つだけです。

$$("#form").mode(() => sending() ? "sending" : failed() ? "error" : "ready");
// → <form data-mode="sending">    CSS: [data-mode="sending"] .spinner { display:block }

真偽で属性の有無を切り替えます（attr(name, false) は文字列 "false" が入る罠があります）。

$$("#panel").toggleAttr("data-open", isOpen);   // 偽なら属性そのものが消える

CSS カスタムプロパティに値を流します。計算・アニメ・レスポンシブは CSS の仕事のまま残ります。

$$("#bar").vars({ progress: () => `${pct()}%` });
// → style="--progress: 60%"       CSS: .fill { width: var(--progress) }

走査

$$("#a").find(".x") .closest("@row") .parent() .children("li")
      .first() .last() .is(".on") .each((el, i) => { … })

next / prev / siblings / eq / index はありません。 構造に依存して静かに壊れるためです（持たないもの）。

イベント

$$("#b").on("click", fn);
$$("#list").on("click", "@row", fn);   // 委譲（後から追加された要素にも効く）
$$("#b").on("click focus", fn);         // 複数
$$("#b").off("click");
$$("#b").click(fn);  $$("#b").click();   // 短縮（引数ありでバインド、無しで発火）

短縮: click dblclick change submit input keydown keyup focus blur mousedown mouseup mouseenter mouseleave scroll
イベント名前空間（click.myui）はありません。後片付けは scope が上位互換です。

追加・削除

$$("#list").append("<li>x</li>");   // 文字列 / ノード / $$(…) / 配列
$$("#list").empty();
$$("#row").remove();      // 張った購読も一緒に片付ける
$$("#row").dispose();     // 要素は残して購読だけ切る

form（フォームの事故）

HTML の required / type="email" / pattern / min を読むので、HTML を1文字も変えずに使えます。

const f = $$("#signup").form();          // HTML の属性から

const f = $$("#signup").form({           // JS 側で足す（HTML の分と合成される）
  company: { required: true, when: () => plan() === "corp" },
  confirm: { same: "password" },
  tel:     { pattern: /^0\d{9,10}$/, message: "電話番号の形式が違います" },
  age:     { min: 18, message: "18歳以上のみお申し込みいただけます" },
});

状態は全部 state なので、そのまま画面に繋げられます。

$$("#count").text(f.errorCount, "件の未入力");
$$("#msg").text(f.firstError);
$$("#mail-err").text(f.error("email"));
$$("#alert").when(f.hasErrors);
$$("#save").disabled(f.submitting);

f.submit(async (values) => {          // 二重送信は自動で防がれる
  await fetch("/api/signup", { method: "POST", body: JSON.stringify(values) });
});

見えていないフィールドは検証しません

HTML5 標準検証は display:none の required でも送信をブロックしますが、 フォーカスできない要素にはエラーを表示できません。「押しても何も起きない」状態になり、離脱します。
bridgey は novalidate を立てて主権を取り、いま見えているフィールドだけを毎回判定します。
既定では送信ボタンを無効化しません（押せて、押したら理由を表示して該当箇所へ飛ばします）。

ルール: required（関数も可） email pattern min max minLength maxLength same when message validate
状態: values errors errorCount hasErrors firstError errorList error(name) valid dirty submitting submitted
操作: submit(handler) submit() validate() reset(values?) focusFirstError() refresh()
オプション: disableSubmit errorAttr validateHidden autoErrorSlot

group（選択）

ラジオ / チェックボックス群を1つの state にします。選択状態の二重管理（checked と .active）が消えます。

const plan    = $$("#plan input").group();     // ラジオ → 選ばれている value
const options = $$("#opt input").group();      // チェックボックス → value の配列

const total = $$.computed(() => options().reduce((s, k) => s + PRICE[k], 0));

component（common.js）

全ページで読まれる common.js に「手続き」を書くと、要素が無いページでも走り、 1箇所の undefined で以降が全部死にます。「登録」だけを書く形にすれば、その両方が消えます。 

$$.component("tabs", ($el, props, ctx) => {
  const current = $$.state(props.start ?? "a");
  $el.find("@tab").each((el) => $$(el)
    .click(() => current(el.dataset.tab))
    .selected(() => current() === el.dataset.tab));
  $el.find("@pane").each((el) => $$(el).when(() => current() === el.dataset.tab));

  const id = setInterval(tick, 1000);
  ctx.scope.add(() => clearInterval(id));   // 要素が消えたら止まる
});
<ul data-component="tabs" data-start="b">…</ul>
  • 要素が無いページでは1行も実行されません（存在チェックの if が不要）
  • 1つの初期化が失敗しても、他は動き続けます（失敗した部品名と、生きている部品名を通知）
  • Ajax で後から追加された要素にも自動で適用され、消えたら自動で片付きます
  • data-* が props になります（"5"→5、"007"は文字列のまま）

$$.mount(root?) で手動走査、$$.unmount(root?) で破棄、 $$("#x").component("tabs", props) で明示適用。属性名は $$.componentAttr("data-...")。

resource / action（通信）

同じ JSON を何度も取り、応答の順序が入れ替わって古い金額が残る——これを構造的に潰します。 前のリクエストは AbortController で中断し、それでも解決した古い応答は世代番号で捨てます。 

const rows = $$.resource(() => fetch("/data.json").then(r => r.json()));
$$("#spinner").when(rows.loading);
$$("#error").when(() => !!rows.error());

// 入力に追従（前の取得は自動で中断される）
const q    = $$("#q").state("");
const hits = $$.resource(q, (word, signal) =>
  fetch(`/search?q=${word}`, { signal }).then(r => r.json()), { debounce: 300 });

二重送信しないアクション。失敗しても running は必ず戻ります（永久 disabled になりません）。

const save = $$.action(async () => { await fetch("/api/save", { … }); });
$$("#save").click(save).disabled(save.running);
$$("#save-error").when(() => !!save.error());

resource: data loading error refetch() abort() ready() / オプション debounce keepPrevious immediate

警告

jQuery は0件でも黙ります。bridgey は「確実にバグ」のときだけ鳴ります。

[bridgey] $$(".price") が0件でした。text() を結びつけられません。
  HTML が変わった可能性があります(class 名の変更・要素の削除・読み込み順)。
  → 壊れにくくするには data 属性で結びつけてください:
     <span data-brg="price"></span>  →  $$("@price")
  • 0件で束縛しようとした（命令的な操作の0件は無害なので黙ります）
  • CSS に無い class 名で表示制御しようとした（似ている名前を提示）
  • repeat のキーが重複している
  • component の初期化に失敗した（生きている部品名も知らせる）
  • 印を書いたのに $$.bind() されていない要素がある
  • 削除した API を呼んだ（代わりの書き方を提示して例外）

本番でうるさければ $$.warn = false。class 名の検査だけ切るなら $$.warnUnknownClass = false。

ヒント

22個ある語を全部覚えなくても、必要になった場面で案内が出ます（警告とは別カテゴリ）。

[bridgey] addClass("active") で状態を表しているようです。
          → .selected(state) が使えます: aria-selected も一緒に付き、
            他の要素から消し忘れることもありません
          (このヒントは $$.hints = false で止められます)

css("display", …) → when() ／ attr(name, false) → toggleAttr() ／ html(一覧) → repeat() も案内します。

日本語入力

電話番号や郵便番号の自動整形、全角→半角、カナ変換——入力しながら値を書き戻す処理は日本のフォームで極めてよくあります。 漢字変換の最中に書き戻すと、変換候補が消える・確定できない・文字が化けます。

bridgey は compositionstart 〜 compositionend の間、 DOM→state と state→DOM の両方を止め、確定した瞬間に一度だけ同期します。 フォームの検証も変換中は走りません（「にほん」の途中で赤くなりません）。

<script> と npm

<!-- CDN。読み込むと window.$$ が生える -->
<script src="https://cdn.jsdelivr.net/npm/bridgey@2"></script>

// npm（型が付く）
import { $$ } from "bridgey";

dist/bridgey.js（min）/ dist/bridgey.dev.js（非min・警告が読みやすい）/ dist/bridgey.esm.js（npm）。TypeScript で書かれているので型定義は実装とズレません。

グローバル名を変える

<script> タグの1箇所だけで変えられます。

<script src="…/bridgey@2"></script>                       // $$
<script src="…/bridgey@2" data-global="$"></script>      // $
<script src="…/bridgey@2" data-global="$$$"></script>    // $$$
<script src="…/bridgey@2" data-global="$_$"></script>    // $_$
<script src="…/bridgey@2" data-global="brg,$$"></script> // 両方

$$ が既に使われていたら（Prototype.js など）、勝手に別名へ逃がさず警告します。 サイトによって名前が変わると、コピーしたコードが動かない原因が分からなくなるからです。 window.bridgey からは常に使えます。bridgey.noConflict() で元に戻せます。

jQuery と同じページ・同じ要素で共存できます（$ は奪いません）。

設定と補助

$$.attr = "data-brg";      // @ が解決する属性名
$$.warn = true;             // 事故の警告
$$.hints = true;            // より良い書き方の提案
$$.warnUnknownClass = true; // true | "all" | false
$$.warnSink = (m) => …;      // 警告の出口を差し替える
$$.version                   // "2.0.0-beta.1"
await $$.tick();            // DOM 反映を待つ
$$.batch(() => { … });       // まとめて1回
$$.untrack(() => … );        // 購読を張らずに読む
$$.effect(() => … );         // DOM 以外に反映したいとき（戻り値で解除）
const s = $$.scope(() => …); s.dispose();   // 片付けの単位
$$.money(23800)              // "23,800"
$$.fn.myPlugin = function () { … };       // プラグイン拡張口

状態の更新は自動でまとまります（同一フレームの書き込みを rAF で1回に）。 .text() を1000回呼んでも reflow は1回です。

持たないもの

呼ぶと、代わりの書き方を教えて例外になります。黙って undefined にはなりません。

$$("#row").next();
// Error: [bridgey] next() は使えません。HTML の構造が変わると壊れるため v2 では
//        提供していません(要素を1つ挟むだけで、例外も出ないまま静かに動かなくなります)。
//        → 構造ではなく名前で引いてください: $$(this).closest("@row").find("@price")
持たないもの 代わりに

show / hide / toggle when(state)
$.ajax / get / post fetch()、競合制御は $$.resource()
$.extend / each / map / trim {...a, ...b} / for...of / Array#map / String#trim
serialize / serializeArray new FormData(form)、検証は form()

width / height / offset getBoundingClientRect()

one / trigger / hover { once: true } / dispatchEvent / mouseenter+mouseleave
ルーター / SPA 化 URL の主権はサーバーに
スコープ付きCSS / 仮想DOM / SSR 入れません

jQuery プラグイン（slick / DataTables 等）は bridgey では動きません。jQuery 本体と併用してください。

v1 からの移行

v2 は破壊的変更です。Svelte / Vue への依存は廃止しました。

// v1                                    v2
useEngine(svelteEngine)              // 削除（エンジンの概念そのものが無い）
mount(Component, { target })         // 削除 → component() / repeat()
state(0) → count.value               // $$.state(0) → count() / count(5)
computed(deps, fn)                   // $$.computed(fn)（依存は自動追跡）
bindText / bindClass / bindAttr      // .text(state) / .toggleClass(n, state) / .attr(n, state)
$$.get / $$.post                     // fetch() / $$.resource()
$$("#x").val() が String サブクラス     // 普通の文字列（=== が期待通り動く）
jQuery 共存は非サポート                 // 公式サポート
